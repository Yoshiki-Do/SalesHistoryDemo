# Sales History Web Application

A web application for searching and viewing sales records.

## Technologies

- C#
- ASP.NET Core MVC (.NET 8)
- Oracle Database
- SQL
- Git and GitHub

## Features

- Search sales records by customer name
- Filter records by date range
- Sort records by sales date or amount
- Display paginated results
- Validate search conditions and handle errors

## Development Workflow

Features are developed in separate Git branches before being merged into `main`.
